# AUG v0.1.0-experimental.1

First experimental reference implementation, open for architectural review and contributions.

AUG generates a validated read-only search interface from annotated backend capabilities.
An optional model proposes a constrained layout from metadata; records are retrieved through
a separate authenticated gateway and rendered by fixed components. The default demo needs
no model key, external backend or certificate installation.

## Included

- Annotated OpenAPI discovery, tenant/scope-aware catalog and `aug.ui/0.1` plans.
- Deterministic planner and optional provider abstraction with constrained proposals/fallback.
- Direct data channel, session validation, permitted-field projection and value-free audit hooks.
- Shared renderer, synthetic multi-tenant demo, optional Archteathos adapter and local MCP Apps spike.
- English integration/security guides, MIT license, issue templates and six contribution briefs.

## Validation

The first snapshot passed Windows/Linux × Node 22/24 GitHub CI. The main suite reports
76 passed, 3 opt-in tests skipped, 0 failed (79 total). CI also launches the actual demo
without a key, checks publication files and audits production dependencies.
The separately executed Archteathos integration reports 10 passed using 13 existing sheets.
See [the publication record](../publication.md) for the exact initial run.

## Known boundaries

This is a small read-only search/table slice, not a production identity or write system.
OpenAPI needs annotations; nested/legacy backends may need adapters. The UI format is
internal, not A2UI. The practical benefit of model layout choice remains an evaluation question.

Claude Desktop has an observed successful direct query; the tested ChatGPT Desktop/Codex
host blocks loopback HTTP. Its real HTTPS path and certificate lifecycle remain open.
No guarantee is made against a compromised host observing rendered data. Provider/layout
tests are largely simulated; live tests are opt-in. Core response streaming bounds remain
an identified hardening task.
