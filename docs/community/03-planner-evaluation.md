# Evaluate the model planner against a deterministic baseline

The optional model can choose titles, labels and authorized table columns within the
existing search layout. Its practical advantage has not been demonstrated.

Define a small set of synthetic tasks and compare deterministic, model-assisted and a
hand-designed baseline. Report completion/error rates or a suitable task-quality measure,
latency, token/cost observations, fallback frequency and the exact model/configuration.

Acceptance: a reproducible protocol and results, including negative findings. Avoid claiming
universal UX improvements from a few examples. No real records should enter the provider.
