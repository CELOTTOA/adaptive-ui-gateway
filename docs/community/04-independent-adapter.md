# Connect an independent backend through the existing contract

Choose a backend with redistributable synthetic fixtures and one useful read operation.
Use annotated OpenAPI directly when possible; document any facade otherwise.

Acceptance: repeatable setup, one authorized search, no results, missing-value handling,
negative access checks, excluded fields and a metadata-only planner-channel check. Record
integration effort and unsupported shapes. Avoid changing AUG core solely for the example.
